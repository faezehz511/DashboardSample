# Financial Transactions & Reconciliation Dashboard

An interactive analytics dashboard for monitoring, reconciling, and analyzing payment, banking, and tax transaction discrepancies across national and provincial levels.

![Dashboard Demo](https://raw.githubusercontent.com/faezehz511/DashboardSample/main/demo.JPG)

## Key Features
- **Advanced Filtering:** Filter by date, organization, taxpayer info, and accounting records.
- **KPI Metrics:** Real-time tracking of total transactions, matched amounts, open discrepancies, and error rates.
- **Geographic Analysis:** Interactive map displaying discrepancy risk levels by province and city.
- **Data Visualizations:** Breakdown by taxpayer type, payment channels, and tax sources.
- **Export Capabilities:** Export filtered reports directly to **Excel**.
